# 🏗️ Soluciones Tecnológicas del Futuro — DevOps Pipeline

Plataforma automatizada de despliegue y monitoreo en AWS con prácticas DevOps.

## 🛠️ Tecnologías utilizadas
- AWS (EC2, S3, CloudFormation, CodePipeline, CloudWatch, Lambda)
- Docker + docker-compose
- Python + Boto3
- GitHub Actions / CI/CD
- Terraform / Ansible

## 📁 Estructura del proyecto
- `/scripts` — Scripts Python para automatización
- `/cloudformation` — Plantillas YAML de infraestructura
- `/docker` — Dockerfile y docker-compose
- `/pipeline` — Configuración CI/CD
